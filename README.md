## Projects

- [gladius](https://github.com/nathwn12/gladius) — Rust MCP server that gives an agent a headless Chrome it drives over CDP: one native binary, no Node, no Playwright.
- [puppet](https://github.com/nathwn12/puppet) — Rust MCP server that screenshots, lists, and drives Windows windows and input without stealing focus, pointer, or keyboard.
- [slowburn](https://github.com/nathwn12/slowburn) — Windows media player with slowed reverb and an A-B loop.
- [potflix](https://github.com/nathwn12/potflix) — Rust app that mirrors the current PotPlayer track to a Discord Rich Presence card.
- [my-chromium-extensions](https://github.com/nathwn12/my-chromium-extensions) — four unpacked Chromium extensions: a per-site loudness target, slowed playback with plate reverb, Crunchyroll presence, and YouTube Music presence.
- [spotify-playlist-to-youtube](https://github.com/nathwn12/spotify-playlist-to-youtube) — copies a public Spotify playlist into YouTube Music without an API key. Python standard library only.
- [arc-installer](https://github.com/nathwn12/arc-installer) — C# and PowerShell installer that applies the ARC icon theme to Windows and restores the stock icons on revert.
- [vencord-bootstrap](https://github.com/nathwn12/vencord-bootstrap) — installs and repairs Vencord from the official upstream release with one PowerShell line.
- [oc-collections](https://github.com/nathwn12/oc-collections) — OpenCode plugins, MCP servers, and tooling, each package installed on its own, never as a bundle.
